Work I have built, what I did on each, and the tools involved.

Responsive Student Profile

A single-page student profile application built as a Cordova project. The layout uses CSS Grid and a mobile-first approach so the same markup reflows cleanly from a phone screen up to a desktop display without horizontal scrolling or cut-off text.

My role: Sole developer — designed the interface, wrote all markup and styles, and set up the Cordova build.

  • HTML5
  • CSS3
  • CSS Grid
  • Apache Cordova
  • Git

Multi-Page Student Profile App

An expansion of the profile application into five separate pages with a shared navigation bar. The navigation switches between a bottom tab bar on phones and an inline menu on larger screens, and it is built entirely with standard HTML links rather than JavaScript routing.

My role: Sole developer — restructured the codebase into separate pages and shared stylesheets, and kept the design consistent across all screens.

  • HTML5
  • CSS3
  • Responsive design
  • Apache Cordova
  • Android emulator

Student Records Manager

A console application that stores and retrieves student records, with menu-driven options to add, search, update and delete entries. Records are written to a local file so the data survives between runs.

My role: Sole developer — designed the data structure, wrote the menu logic and handled file reading and writing.

  • Python
  • File handling
  • Object-oriented programming
